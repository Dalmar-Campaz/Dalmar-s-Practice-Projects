Introduccion a Git

Git es un sistema de control de versiones distribuido diseñado para rastrear cambios en el código fuente durante el desarrollo de software. A diferencia de los sistemas centralizados, cada directorio de Git en cada computadora es un repositorio hecho y derecho con un historial completo y capacidades de seguimiento de revisión independientes de la red o de un servidor central.

git --version
Configuracion e Inicializacion

Antes de comenzar a rastrear archivos, debes configurar tu identidad de usuario global en Git. Esto asegura que todos tus commits queden atribuidos correctamente con tu nombre y correo electrónico.

  • Configurar usuario: git config --global user.name "Tu Nombre"
  • Configurar email: git config --global user.email "tu@email.com"

Para iniciar un repositorio local en una carpeta existente:

git init

Si deseas descargar un proyecto remoto desde GitHub o GitLab:

git clone https://github.com/usuario/repositorio.git
Flujo de Trabajo Basicos

El flujo de trabajo en Git consta de tres estados principales: el directorio de trabajo (Working Directory), el área de preparación (Staging Area) y el repositorio (Repository).

  • Modificas tus archivos en el directorio de trabajo.
  • Preparas los archivos agregando capturas de sus cambios al área de preparación.
  • Confirmas los cambios (commit), lo que toma los archivos tal como están en el área de preparación y almacena esa captura de manera permanente en el directorio de Git.
# Ver el estado de los archivos
git status # Agregar un archivo al Staging Area
git add index.html # Agregar todos los archivos modificados
git add . # Guardar los cambios con un mensaje descriptivo
git commit -m "Agregar estructura HTML inicial"
Manejo de Ramas

Las ramas te permiten separar tu trabajo del hilo principal de desarrollo (usualmente llamado main o master). Puedes crear una rama para trabajar en una nueva funcionalidad o corregir un error sin afectar el código estable.

  • Listar ramas locales: git branch
  • Crear una nueva rama: git branch nueva-feature
  • Cambiar a la nueva rama: git checkout nueva-feature / git switch nueva-feature
  • Crear y cambiar en un solo paso: git checkout -b nueva-feature

Para fusionar los cambios de tu rama secundaria de vuelta a la rama principal:

git checkout main
git merge nueva-feature
Repositorios Remotos

Para colaborar con otros desarrolladores o respaldar tu código en la nube, debes sincronizar tu repositorio local con un repositorio remoto.

  • Vincular un repositorio remoto: git remote add origin https://github.com/usuario/repositorio.git

  • Subir cambios locales al servidor remoto:

    git push -u origin main

  • Descargar e integrar los cambios más recientes del servidor:

    git pull origin main
